# Cat Photo App

A static HTML/CSS practice page based on a Cat Photo App layout. The project includes sections for cat photos, cat lists, and a cat photo form. A small JavaScript file adds the current date to the page.

## Features

- Semantic HTML sections
- Image and link practice
- Ordered/unordered lists
- Radio buttons and checkboxes
- Form markup
- Current date display with JavaScript

## How To Run

Open `index.html` in a browser.

## Files

```text
index.html
styles.css
script.js
```

## What I Practiced

- HTML structure
- Forms and inputs
- Linking stylesheets
- Basic DOM text updates
- Static page styling
